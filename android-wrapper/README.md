# AXON Android icon-fix test build

Minimal WebView wrapper for https://axon-ai-trading.vercel.app/, using the selected dark-mode AXON launcher icon.

This test build uses package id com.axon.aitrading.iconfix.debug so it can be installed alongside previous AXON test APKs. It is online-only and relies on the web application. It is a debug build, not a release-signed Google Play package. Keep live trading disabled until all checks are complete.
